# Controle de gastos

Aplicação interativa para acompanhar gastos, com resumo financeiro, filtros e dados salvos no navegador (LocalStorage).

**Ao vivo:** https://samueldevmi.github.io/portfolio/controle-gastos/

> Também existe uma [versão backend](../gastos-api/) deste projeto, com API REST e banco de dados de verdade.

## Tecnologias

JavaScript, LocalStorage

## Como rodar

Abra o `index.html` direto no navegador — não depende de servidor ou build.
