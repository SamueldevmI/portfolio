Behind the scenes

How this portfolio was built

I'm Samuel Mickael, a web developer from Campo Grande, Brazil. My clients are local businesses, so the portfolio is in Portuguese, but there's a lot of engineering behind the comic-book look. This page is for companies, recruiters and other developers.

No framework, no server

Plain HTML, CSS and JavaScript, hosted for free on GitHub Pages. Nothing to install and no monthly bill. It's the same way I deliver client sites: fast to open and cheap to maintain.

The soundtrack is played by the browser

The background track isn't an audio file: every piano note, bass line and beat is generated on the fly with the Web Audio API. It adds nothing to the page weight, changes mood with the section you're reading, slows down at night and ducks when you start typing. It only plays if you press play.

An animated comic book that doesn't freeze your phone

  • Animations only touch position and opacity, which phones handle easily.
  • People who ask for reduced motion in their device settings get a still page.
  • Lower sections are only rendered when they get close to the screen, and scripts the page doesn't need to appear load later.
  • The Spanish version is only downloaded if someone taps "ES".

One price file drives everything

Prices, timelines, packages and add-ons live in a single file. The industry pages, the tips, the price builder and the proposals are generated from it. Changed a price? One command regenerates everything, and an automated check on GitHub makes sure no page keeps an old value.

Tools built for this site

  • Automatic blue theme: generated from the red one, no hand-copied styles.
  • Link previews: the card that shows up when a link is shared on WhatsApp is generated by a script, one image per page.
  • Comic-style photo: made with a small tool of my own that runs in the browser.
  • Free QR code generator: runs on the visitor's phone; nothing they type leaves the device.
